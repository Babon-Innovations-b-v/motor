# examples/soma_template/

MOTOR run on public data only: SOMA-X's template body (Apache-2.0) standing still in its bind pose. Its files are
downloaded at run time at a pinned revision and checked by sha256; nothing of SOMA-X is committed. The rig it builds
equals SCORE's clips rig (the 27 joints, the bind, the LOD-low skin and faces, the folded skin weights) to float32's
rounding (checked 2026-11-15). It is a run, not a validation: no number it prints is a result.
